# Logos

- `qrfinity-logo.svg`: mark + wordmark. Mark `#0f5132` (evergreen), dot `#f5c542` (signal), wordmark `#14201a` (ink). Use on `ground` or `surface`.
- `qrfinity-logo-reversed.svg`: mark and wordmark `#fafaf7`, dot `#f5c542`. Use on `evergreen` or dark photos.
- `qrfinity-logo-mono.svg`: everything `#14201a` (ink). Single-colour print.
- `qrfinity-mark.svg`, `qrfinity-mark-reversed.svg`, `qrfinity-mark-mono.svg`: the mark alone, same inks as above.
- `qrfinity-app-icon.svg`: 512 × 512, `radius` 112 evergreen tile with the paper mark and yellow dot. Favicon, PWA and social avatar.

The inks are fixed in each file; pick the file that matches the background rather than recolouring. The wordmark is outlined Bricolage Grotesque 800.
