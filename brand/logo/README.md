# Logos

- `qrfinity-logo.svg`: woven QR mark `#0f5132` (evergreen) + "finity" `#14201a` (ink) with i-dots `#f5c542` (signal). Use on `ground` or `surface`.
- `qrfinity-logo-reversed.svg`: mark and wordmark `#fafaf7`, i-dots `#f5c542`. Use on `evergreen` or dark photos.
- `qrfinity-logo-mono.svg`: everything `#14201a` (ink). Single-colour print.
- `qrfinity-mark.svg` (`#0f5132`), `qrfinity-mark-reversed.svg` (`#fafaf7`), `qrfinity-mark-mono.svg` (`#14201a`): the woven QR mark alone.
- `qrfinity-logo-reversed-email.png`: the reversed logo as a 367 × 96 PNG (shown at 122 × 32) for the evergreen email header, because Gmail and Outlook don't show SVG. Regenerate with `node apps/web/scripts/build-email-logo.mjs` after the logo changes.
- `qrfinity-app-icon.svg`: 512 × 512 evergreen tile, corner radius 112, with the paper mark. PNG exports at 512, 180 (Apple touch icon) and 32 (favicon) sit beside it in the repo.

The inks are fixed in each file; pick the file that matches the background rather than recolouring. The mark is traced from the approved reference drawing; the wordmark is outlined Bricolage Grotesque 800, set 4 % of the mark's height away from it.
