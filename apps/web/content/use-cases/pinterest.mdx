## What a Pinterest QR code does

A Pinterest QR code opens your profile or a board in one scan. It turns a printed product, card or stall into a way to browse everything else you make, and to save it for later.

Makers put them on craft-fair stands, product tags and packaging, wedding and event planners on mood boards and brochures, and shops on display cards linking to style ideas.

## How to make a Pinterest QR code

1. **Check that Social and Pinterest are selected.** This page loads the Social type with Pinterest chosen as the Platform.
2. **Enter your username, or paste a board link.**
3. **Choose static or dynamic.** Static works forever with nothing in between. Dynamic lets you point it at a different board later and counts scans.
4. **Make it yours.** The Pinterest logo is already in the middle. Pick colours and a frame like “More ideas on Pinterest”.
5. **Download or save.** Download a static code right away, or save a dynamic code to your free account.

## Design and print tips

- **Link to the board that matches the product.** A tag on a candle that opens your candle board beats a link to everything.
- **On tags and packaging, keep it small but clear:** 2 to 2.5 cm, with a blank margin all round.
- **Pinterest red for the frame.** Keep the code itself dark on a light background.
- **Tell people what they’ll find.** “50 ways to style this scarf” earns more scans than “Pinterest”.

## Static or dynamic?

<Recommendation pick="either">
A static code is fine for your profile. Choose dynamic for packaging and tags, so you can point the same print at a new board each season and see how many people scan.
