## What a Google Forms QR code does

A Google Forms QR code opens your form in one scan, on the phone already in people’s hands. No typing a long link from a poster, no passing round a clipboard. Responses land in your form and its spreadsheet as usual.

Teachers use them for exit tickets and quizzes, events for feedback and sign-ups, clubs for membership forms, and shops for customer surveys on receipts and tables.

## How to make a Google Forms QR code

1. **Copy your form’s link.** In Google Forms, choose Send, then the link icon, and tick “Shorten URL”.
2. **Paste it into Website address.** The link is checked as you type.
3. **Choose static or dynamic.** Dynamic lets you swap in a new form later and shows how many people scanned.
4. **Make it yours.** Pick colours and a frame like “Tell us what you think”.
5. **Test it, then download or save.** Scan the code and send a test response, then delete it from the responses tab.

## Design and print tips

- **Say how long it takes.** “2-minute survey” gets far more responses than “Survey”.
- **Keep the form short and phone-friendly.** Multiple choice beats long text boxes on a small screen.
- **On slides, leave it up.** Show the code at least a metre wide on the screen while people answer.
- **Use one code per place.** A separate dynamic code on each table, flyer or slide shows which one people actually used.

## Static or dynamic?

<Recommendation pick="dynamic">
Forms change: new terms, new events, a fresh survey each year. A dynamic code lets you point the same printed code at the next form without reprinting, and shows how many people scanned. It’s free and never expires.
