## What a Google Drive QR code does

A Google Drive QR code opens a Doc, Sheet, Slides deck, PDF or folder in one scan. It’s the quickest way to hand out a file to a room, a class or a team without typing a long Google link.

Teachers use them for handouts and reading lists, offices for policies and rotas, event organisers for slides and photo folders, and clubs for timetables and minutes.

## How to make a Google Drive QR code

1. **Share the file.** In Google Drive, choose Share, set General access to “Anyone with the link” and Viewer.
2. **Copy the link** and paste it into Website address.
3. **Keep it dynamic.** This page starts with a dynamic code, so you can swap in a new file later without reprinting.
4. **Make it yours.** Pick colours and a frame like “Slides and notes”.
5. **Save and test.** Save the code, then scan it from a phone that isn’t signed in to your Google account, to check it opens for everyone.

## Tips for shared files

- **Test signed out.** Your own phone is signed in to your account, so it always opens; a stranger’s may not.
- **Share as Viewer** for anything public.
- **Use a folder for collections.** One code to a folder of slides, photos or worksheets beats one code per file.
- **Long Google links make busy codes.** A dynamic code holds a short link instead, so it stays simple and small.
