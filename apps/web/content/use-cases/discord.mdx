## What a Discord QR code does

A Discord QR code opens your server invite in one scan. Nobody has to type a random invite code from a poster or a stream; they scan, tap Join and they’re in.

Streamers put them on overlays and end screens, game shops and clubs on posters, teachers and societies on handouts, and event organisers on badges and slides.

## How to make a Discord QR code

1. **Create an invite that doesn’t expire.** In your server, choose Invite People, then edit the invite link and set “Expire after” to Never.
2. **Paste the invite link into Website address.** It looks like discord.gg/ followed by a code.
3. **Keep it dynamic.** This page starts with a dynamic code, so you can swap in a new invite if this one is ever deleted.
4. **Make it yours.** The Discord logo is added automatically. Pick colours and a frame like “Join the community”.
5. **Save and test.** Save the code to your free account, scan it with your phone, and check the invite opens your server.

## Design and print tips

- **Say what the server is for.** “Weekly game nights” or “Homework help” earns more joins than “Join our Discord”.
- **On streams, keep it on screen.** At least 5 seconds, large enough to scan from a sofa.
- **Use Discord blurple for the frame.** Keep the code itself dark on a light background.
- **Check your server’s welcome screen** and rules channel before you print: that’s the first thing new members see.

## Static or dynamic?

<Recommendation pick="dynamic">
Invites get deleted, reset or expire, and every printed static code would die with them. A dynamic code lets you swap in a new invite in seconds without reprinting, and counts how many people scanned. It’s free and never expires.
</Recommendation>
