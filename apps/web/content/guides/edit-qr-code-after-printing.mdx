You can change where a QR code goes after printing if it’s a dynamic code. A dynamic code holds a short link, and you choose where that link sends people, so you can change it from your dashboard at any time and every printed copy follows. A static code holds its content directly in the pattern, so it can’t be edited; changing it means a new code and a reprint.

## Why only dynamic codes can be edited

A static code is the content itself, written into the pattern of squares: the web address, the Wi-Fi password, the contact details. Change one letter and you get a different pattern.

A dynamic code holds a short link, like `qrfinity.link/aB3xK9q`. When someone scans it, the link sends them on to the destination you set. The pattern never changes; the destination behind it does. For more, see [static vs dynamic QR codes](/guides/static-vs-dynamic-qr-codes).

## How to edit a dynamic QR code on QRfinity

1. **Sign in and open your dashboard.** Every dynamic code you’ve saved is listed there.
2. **Choose the code.** Its page shows where it goes now and how many people have scanned it.
3. **Change the destination.** Paste the new address and save. Scans go to the new address within a minute or so.

Your scan history stays with the code. You can also change a dynamic contact card’s details, or set the code to change by itself after a date or a number of scans; see [changing a code after a date](/guides/change-qr-code-after-date-or-scans).

## Stuck with a static code?

If the static code holds a link to **a website you control**, you don’t need to reprint. Set up a redirect on your website from that old address to the new page. Your web host or website builder calls it a redirect or a 301.

If the code holds a link to **someone else’s site**, a Wi-Fi password or contact details, it can’t be changed. Make a dynamic code for the next print run, so you’re never stuck again.

## Using one code on many materials

A QR code can go on as many things as you like: the menu, the window, the flyer and the business card can all carry the same code. Two things to think about:

- **Tracking:** one code counts every scan together. To see which material works, give each one its own dynamic code. They can all go to the same page.
- **Size:** the same code must be printed larger where people scan from further away. A code on a poster needs to be much bigger than one on a card; see [QR code size for print](/guides/qr-code-size-for-print).

## Will an edited code keep working?

On QRfinity, yes. Our codes never expire, and dynamic codes keep working whether or not you ever pay us. Before you print a dynamic code from any service, check what happens when a trial or plan ends; with some, codes stop working. See [do QR codes expire?](/guides/do-qr-codes-expire).
