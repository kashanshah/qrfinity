Code 39 is an older barcode many systems still expect: ID badges, library cards, some industrial and government labels. It holds capital letters, digits and a few symbols, and is easy for any scanner to read. Type your text above and download a scan-tested barcode; PNG and JPG are free.

## When to use Code 39

Use Code 39 when a system or customer asks for it, such as a badge reader, a library system or a parts label specification. If you have a free choice, [Code 128](/barcode-generator/code-128) holds more characters in less space and is read by the same scanners.

## Tips for Code 39 labels

- **Keep it short.** Each character adds noticeable width.
- **Capitals only.** Lowercase letters are turned into capitals; check that your system expects that.
- **Keep the margins** on both sides, and print dark bars on a light background.
