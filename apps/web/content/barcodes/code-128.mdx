Code 128 is the everyday barcode for labels: it holds letters, digits and symbols, packs numbers tightly, and every barcode scanner reads it. Type your text or number above and download a scan-tested barcode; PNG and JPG are free.

## What people use Code 128 for

- **Inventory and SKUs:** shelf labels, bin locations, product SKUs.
- **Asset tags:** laptops, tools and equipment, with a serial number or asset ID.
- **Shipping and returns:** order numbers, return codes and package IDs.
- **Tickets and passes:** a ticket number that a scanner at the door looks up.
- **Amazon FBA:** FNSKU labels use Code 128; the [FNSKU label maker](/barcode-generator/amazon-fnsku) adds the title and condition for you.

## Tips for readable Code 128 barcodes

- **Shorter is better.** Every character adds width. Use a short ID and keep the details in your system.
- **Mind the bar width.** The generator shows the narrowest bar as you resize; stay above 0.19 mm.
- **Keep the margins.** Leave blank space on both sides, at least ten times the narrowest bar.
- **Thermal labels:** print at 100% so bars land on whole printer dots; scaled images print uneven bars.

For systems that only accept capitals and digits, use [Code 39](/barcode-generator/code-39). For cartons with a GTIN, use [ITF-14](/barcode-generator/itf-14).
