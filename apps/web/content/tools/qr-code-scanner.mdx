## What the scanner can read

It reads every kind of QR code our generator makes, and the common formats other generators use:

- **Links**, including short links and QR service redirects, which it labels so you know what you’re about to open
- **Wi-Fi** network names, passwords and security type
- **Contact cards** (vCard): name, phone numbers, email, address and notes
- **Email, SMS and phone** codes, with the prepared message
- **WhatsApp chats, map locations and calendar events**
- **Plain text**, shown exactly as stored

“Exactly what’s in the code” shows the raw content, character for character, so nothing is hidden or reinterpreted.

## Check a link before you open it

QR codes are a common way to slip someone a bad link, because you can’t read the address by looking at the code. The scanner shows you the full address first. Short links and QR service redirects hide the final address, so you can ask us to check where they lead, and whether the page still works, without opening it yourself.

## Make your own copy that never expires

Found a code you want to reuse, like your café’s Wi-Fi or a contact card? “Open in the generator” fills in the same content. Codes made on QRfinity never expire, have no watermark and download free in PNG, SVG, PDF and EPS.

If a code you rely on stopped working, use the [QR code checker](/qr-code-checker) to find out why.
