Nonprofits print a lot: appeal letters, event posters, collection boxes, annual reports. A QR code on each takes people straight to the donation page, the volunteer form or the event, and a dynamic code tells you how many people scanned each one. QRfinity’s codes are free, have no scan limits and never expire, so a code on a collection box keeps working for as long as the box does.

## Track every appeal

Make one dynamic code per appeal, mailer, poster or event. They can all go to the same donation page; each still counts its own scans, with the days and hours people scanned, devices and countries. Compare them at the end of the campaign and put your budget where people responded. We don’t store anyone’s IP address.

## One print run, many campaigns

Collection boxes, banners and display stands outlast any single appeal. With a dynamic code, the same print can point at the winter appeal, then the summer fun run, then a thank-you page, changed from your dashboard or on a date you set. See [how to change a code after a date](/guides/change-qr-code-after-date-or-scans).

## Keep donation codes safe

Donation codes on boxes and posters are a target for fake stickers. Print codes into the material, put your organisation’s name and the donation address beside them, and check them regularly. Our [guide to tampering](/guides/protect-qr-codes-from-tampering) has the details.
