## Why do dynamic QR codes stop working?

A dynamic code doesn’t hold your web address. It holds a short link on the provider’s own domain, and every scan goes through their server before reaching your page. That’s what lets you edit and track it. It also means the provider decides whether to keep forwarding scans.

Free trials often last 7 or 14 days. {/* source: https://qrfy.com/en, seen 2026-10-16; https://www.qr-code-generator.com/pricing/, seen 2026-10-16 */} Codes made during that time look exactly like permanent ones, so it’s easy to print hundreds before the trial ends. Paid plans can stop too: some providers keep codes running for a grace period after a subscription is cancelled, then switch them off. {/* source: https://support.qr-code-generator.com/hc/en-us/articles/7665399659277-How-do-I-cancel-my-QRCG-by-Bitly-subscription, seen 2026-10-16 */} None of this is hidden; it’s usually in the provider’s help pages. It’s just rarely where people look before printing.

## How do I recover a deactivated code?

You have two realistic options.

**1. Reactivate it with the original provider.** Upgrading the same account you made the code with usually restores the same code, so everything already printed works again, often within an hour. Some providers say this works no matter how long ago the code lapsed. {/* source: https://support.qr-code-generator.com/hc/en-us/articles/7665046137613-What-happens-to-my-account-and-QR-Codes-when-the-trial-expires, seen 2026-10-16 */} Others keep account data only for a limited time, after which the code may not be restorable. {/* source: https://www.qrcode-tiger.com/faq, seen 2026-10-16 */} Creating a new account, or a new code with the same destination, won’t bring the old code back. {/* source: https://support.qrfy.com/en/articles/6998446-how-can-i-reactivate-my-qr-codes, seen 2026-10-16 */} If the code is on something expensive to reprint, such as packaging or permanent signage, this is often the cheapest fix in the short term.

**2. Replace the printed code.** Make a new code and put it over or in place of the old one. Stickers work well for menus, table tents and posters. It costs a reprint, but it ends the dependency.

What you can’t do is move the old code to another company. The short link’s domain belongs to the original provider, so only they can decide where it points.

## How do I fix a code that won’t scan at all?

If the phone doesn’t react, the problem is the print, not a service. Check these in order:

1. **Size.** Under 2 cm wide is too small for many phones. For distance, make it about one tenth of the scanning distance. See the [print size guide](/guides/qr-code-size-for-print).
2. **Contrast.** Dark code on a light background. Pale colours, light-on-dark designs and busy backgrounds cause most failures.
3. **Margin.** The code needs blank space around it, ideally 4 modules on every side. Text or edges inside that space confuse cameras.
4. **Glare and finish.** Glossy laminate under bright lights can blind the camera. Matte works better.
5. **Damage.** Scratches, fading, folds and curved surfaces all remove information. A higher error correction level makes future prints more forgiving.

Our generator runs a live scan check that warns about each of these before you download. The [design guide](/guides/qr-code-design-best-practices) explains the details.

## How do I stop it happening again?

Choose codes that don’t depend on anyone’s billing system:

- **Use static where you can.** If the content won’t change, a static code holds it directly and can’t be switched off by anyone. Wi-Fi, contact cards and permanent pages are good fits.
- **Use a provider that never deactivates dynamic codes.** On QRfinity, dynamic codes are free, unlimited and never expire. We never deactivate, pause or meter a free code, and that promise is in our [terms](/terms).
- **Keep a record.** On QRfinity you can export all your codes and destinations as CSV or JSON from your account at any time.
- **Test before every print run.** Print one, scan it with a few phones, then print the rest.

More on what “no expiration” should mean is on [QR codes with no expiration](/qr-code-no-expiration), and the [do QR codes expire?](/guides/do-qr-codes-expire) guide covers the background.
